## PROJECT OVERVIEW
This project focuses on In-Vehicle Infotainment (IVI) systems and simulates the message flow between the Media Service, Audio Framework, and Audio HAL.

## OBJECTIVE
To demonstrate how user commands such as Play, Pause, and Resume propagate through the IVI audio stack and reach the audio hardware.

## METHOD
The project uses simulated Android-style logs to represent the message flow. It is a conceptual simulation and does not involve real vehicle hardware or an actual Android Automotive deployment.
